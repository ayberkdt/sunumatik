# Importance model

Rank ideas relative to the audience and presentation purpose, not by source order.

| Criterion | Question |
|---|---|
| Conclusion dependency | Does the final conclusion fail without this idea? |
| Evidence strength | Is the idea supported directly and credibly? |
| Explanatory leverage | Does it make several later results understandable? |
| Audience relevance | Does it change the audience's understanding or decision? |
| Misconception risk | Would omission create a likely false interpretation? |
| Novelty | Is it new relative to this audience's baseline? |

Use high, medium, or low rather than false numerical precision.

## Classification

- Essential: required in the main narrative.
- Supporting: useful when time permits or when a dependency must be explained.
- Appendix: needed for questions, reproducibility, or specialist review.
- Omit: repetitive, tangential, unsupported, or irrelevant to the presentation decision.

## Insight record

For each essential idea capture:

- claim or concept;
- plain-language meaning;
- source or evidence IDs;
- observation, inference, hypothesis, projection, or recommendation;
- audience relevance;
- prerequisite concepts;
- likely misconception;
- limitation that must travel with the claim;
- one visual or equation that could carry it.

Do not select only positive results. A limitation, null result, or unresolved conflict can be the decisive insight.
