# Scientific narrative models

## Conference research talk

Question → knowledge gap → method → key evidence → interpretation → limitations → contribution → next work.

Lead with the result when the audience already knows the field. Keep literature review short and move robustness checks to appendix.

## Thesis defense

Problem → contributions → theoretical frame → methods → studies or work packages → synthesis → limitations → original contribution → future work.

Explicitly map each result to a thesis contribution.

## Mission concept or review

Mission need → objectives → requirements → architecture → instruments/subsystems → operations → performance evidence → risk → schedule/cost → decision request.

For formal reviews, link claims to requirement and verification IDs.

## Technical tutorial

Motivation → mental model → notation → worked example → edge cases → practice or demo → summary.

Introduce symbols before using them and avoid showing an unexplained final formula.

## Scientific proposal

Significance → gap → hypothesis/objective → method → feasibility → expected outcomes → risks and alternatives → resources → request.

Distinguish expected outcomes from existing observations.

## Public outreach

Human-scale question → surprising observation → explanation → scale comparison → discovery process → uncertainty → why it matters.

Use analogy as a bridge, then state where the analogy breaks.
