# Routing matrix

| Need | Primary skill | Add when |
|---|---|---|
| Importance and selection | `distill-scientific-insights` | Source material is broad, dense, or poorly prioritized |
| Story and pacing | `structure-scientific-narrative` | Source material must become slides |
| Rhetorical movement | `craft-scientific-storytelling` | The sequence is accurate but flat, fragmented, or sensational |
| Copy substance | `write-assertive-slide-copy` | ANY visible copy is written; mandatory guard against prose walls and keyword confetti |
| Turkish copy | `write-turkish-slide-copy` | Visible copy or notes are written in Turkish |
| English copy | `write-english-slide-copy` | Visible copy or notes are written in English |
| Copy density | `enforce-slide-copy-density` | Text competes with visuals or requires small type |
| Claims and citations | `verify-scientific-evidence` | Facts, papers, figures, or data matter |
| Theme and previews | `design-space-science-deck` | Visual direction is not fixed |
| Figma implementation | `import-figma-science-deck` | A Figma file or frame is authoritative |
| Equations | `typeset-tex-equations` | TeX, notation, units, or derivation appears |
| Charts and diagrams | `create-scientific-visuals` | Data or mechanism needs a visual |
| Motion and simulation | `design-scientific-motion` | Time, sequence, state, orbit, propagation, or transformation must be explained |
| HTML runtime | `build-html-science-deck` | Browser artifact must be created or edited |
| Migration | `convert-science-presentation` | PPTX, PDF, or legacy deck is the source |
| Final QA/export | `audit-export-science-deck` | A rendered deck exists |

## Runtime decision

- Choose static single-file for low interactivity and maximum portability.
- Choose Reveal.js for standard presentation mechanics and notes.
- Choose React/Vite for reusable components, simulations, and interactive scientific visuals.
- Choose Next.js only for portals, authentication, CMS, or server-side workflows.

Do not use runtime choice as a proxy for visual quality.
