# Porcelain Ink

Light editorial theme in the documentation-grade register of Stripe and
Notion: warm porcelain canvas, true-white working surfaces, soft-black ink,
and a single measured indigo used the way premium fintech uses brand color —
sparingly, for wayfinding and emphasis, never as wallpaper.

```css
:root {
  --bg: #F6F4EF;
  --surface: #FFFFFF;
  --text: #23262B;
  --muted: #656A73;
  --accent: #44599C;
  --signal: #178F6E;
}
```

Best for methods decks, funding boards, and cross-disciplinary audiences that
will also read the slides as a document. White surfaces carry evidence panels
and tables; the porcelain canvas stays visible as margin so slides breathe.
Indigo marks structure (kickers, active states, reference lines) and at most
one emphasized claim per slide. Source Serif or a quiet serif for display,
Inter for body, tabular numerals everywhere data appears. Avoid gradients,
drop-shadow stacks, and letting the indigo drift toward saturated AI blue.
