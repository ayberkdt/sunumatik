# Cosmic Scholar

High-formality dark academic theme for research talks and scholarly synthesis.

```css
:root {
  --bg: #111936;
  --surface: #182246;
  --text: #f3efdc;
  --muted: #b9bfd2;
  --accent: #d7c765;
  --secondary: #5f9ea0;
}
```

Use Source Serif 4 or STIX Two Text for restrained display moments, Source Sans 3 for body, IBM Plex Mono for annotations, and STIX Two Math for equations. Use thin rules, catalog labels, and one small archival annotation per slide. Keep motion minimal. Avoid full-slide italics, excessive star fields, and low-contrast yellow text.
