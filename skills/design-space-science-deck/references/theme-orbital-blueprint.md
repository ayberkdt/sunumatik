# Orbital Blueprint

Technical high-density theme for aerospace systems and orbital mechanics.

```css
:root {
  --bg: #071b2b;
  --surface: #0b2940;
  --text: #e8f4f8;
  --muted: #9cb9c5;
  --accent: #52d6d3;
  --warning: #f0b45a;
  --grid: rgba(82,214,211,.12);
}
```

Use IBM Plex Sans and Mono with STIX Two Math. Use precise grids, coordinate ticks, restrained orbital arcs, requirement IDs, and cyan/amber emphasis. Animate propagation or orbit only when explanatory. Avoid fake cockpit chrome, dense glow, and unlabeled decorative trajectories.
