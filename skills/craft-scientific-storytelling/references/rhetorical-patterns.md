# Rhetorical patterns for scientific presentations

Use rhetoric to organize attention, never to outrun evidence.

## Productive openings

- Question: establish a specific unresolved problem.
- Discrepancy: contrast expectation with observation.
- Consequence: state what a decision affects without exaggeration.
- Scale: translate an unfamiliar magnitude into a truthful comparison.
- Result first: lead with the finding when the audience already knows the setup.
- Constraint: begin with the obstacle that shapes the method or mission.

Avoid generic quotations, dictionary definitions, ceremonial greetings on the slide, and unsupported shock statistics.

## Section movement

- Claim → evidence → interpretation → limitation.
- Expectation → observation → discrepancy → explanation.
- Objective → constraint → design choice → measured consequence.
- Known → unknown → test → result → remaining uncertainty.
- Current state → decision alternatives → trade-off → recommendation.

## Transition functions

A transition should explain why the next question is necessary. Use dependency, contrast, consequence, scale change, or unresolved uncertainty. Do not rely on repetitive verbal signage.

## Intensity calibration

Prefer:

- unexpected under this model;
- a meaningful difference;
- changes the feasible range;
- narrows the explanation;
- the strongest evidence in this dataset.

Avoid unless explicitly justified:

- shocking;
- unbelievable;
- revolutionary;
- game-changing;
- proves once and for all;
- changes everything;
- never before seen.

## Rhythm

Vary slide functions. Follow a dense evidence slide with synthesis or a visual pause. Use callbacks only when they close a real question. End by resolving the central question, naming uncertainty, and stating the next decision or investigation.
