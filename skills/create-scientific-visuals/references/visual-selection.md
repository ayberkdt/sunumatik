# Visual selection

Start with the question, not the chart library.

| Question | Preferred forms |
|---|---|
| Compare magnitudes | dot plot, bars, interval plot |
| Show distribution | histogram, density, box/violin, ECDF |
| Show relationship | scatter, regression with uncertainty, residuals |
| Show change over time | line, step, event timeline |
| Show uncertainty | interval, band, ensemble, posterior distribution |
| Show composition | stacked bar when totals matter; avoid decorative pies |
| Show spatial data | map with projection, scale, coordinates |
| Show process | flow or sequence diagram |
| Show hierarchy | tree or architecture diagram |
| Explain mechanism | annotated illustration or staged diagram |

## Integrity checks

Label units and transformations. State sample size. Show missing data intentionally. Mark observed, fitted, simulated, and projected series with redundant line or marker styles. Explain smoothing and aggregation. Use zero baselines when required for valid magnitude comparison.

## Presentation checks

Use one primary takeaway, direct labels when practical, high contrast, and a color-blind-safe palette. Keep a short caption and accessible summary. Preserve source data and transformation code.
